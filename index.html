RailGuard System

Advanced Hardware-Based Detection for Metro Platform Safety and Intrusion Prevention

The Innovation

The RailGuard system implements a continuous, hardware-based intrusion detection architecture designed to secure metro platform safety zones through distributed sensing and deterministic logic processing.

Real-Time Monitoring

Ensures safety via active through-beam sensors that form fixed detection paths parallel to the safety line[cite: 17, 44].

Intelligent Deactivation

The system intelligently monitors train movement to pause during boarding and reactivate post-departure[cite: 18, 29].

Non-Intrusive Install

Uses mechanical clamping that requires no platform civil modifications or floor-laid wiring[cite: 46, 61, 65].

Technical Architecture

This system operates on a multi-layered hardware approach to ensure high reliability and minimal false alarms[cite: 15, 85].

Sensing Layer

Combines Industrial IR Through-Beam sensors for breach detection and Ultrasonic sensors for proximity-based train monitoring[cite: 17, 18, 89].

Control Logic

High-speed processing via dual-controller architecture (Microcontroller + Single Board Computer) utilizing debounce logic[cite: 23, 89].

Actuation

Electrically isolated relay modules trigger immediate audio-visual indicators and control room alerts[cite: 34, 35, 36].
