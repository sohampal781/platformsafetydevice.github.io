RailGuard Safety System
Hardware-Based Yellow Line Breach Detection for Metro Rail Stations

Developed at Institute Of Engineering & Management, Kolkata

Why Use This System?

Current Metro systems often rely on reactive CCTV monitoring or manual supervision. RailGuard provides a proactive, real-time solution to prevent accidents before they happen.

Eliminate Human Error

Removes the dependency on human response time by using deterministic hardware logic for instant detection[cite: 82, 15].

Cost-Effective Safety

Significant cost savings through lower manpower requirements and low power consumption[cite: 52].

Zero Civil Modification

Installs using mechanical clamps on existing railings—no drilling or floor modification required[cite: 57, 61].

System Features

Sensing Layer

Active IR through-beam sensors form a fixed virtual wall parallel to the yellow line[cite: 17].

Intelligent Logic

Ultrasonic sensors monitor train movement to automatically deactivate the system during boarding and reactivate after departure[cite: 18, 29].

Fail-Safe Actuation

Relay outputs default to a fail-safe state in case of power loss, ensuring continuous safety[cite: 38].

Real-Time Alerts

Immediate Audio-Visual triggers (Buzzer + LED) and external system logging[cite: 36, 44].

Operational Principle

The system uses an IR transmitter/receiver pair to monitor obstructions in the restricted zone.
